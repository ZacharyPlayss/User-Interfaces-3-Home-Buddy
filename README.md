# Homebuddy
Homebuddy is een User Interface project waarin mijn kennis van React uitgebreid werd.
Er wordt gebruik gemaakt van zustand stores, de react compiler.

## Realtime
De applicatie beschikt ook over realtime updates met een "databank" door het gebruik van polling.

### Polling ? Geen websockets?
Er wordt gebruik gemaakt van polling zodat sockets niet benodigd zijn.
Deze vermoeilijke namelijk horizontaal schalen op een deployment environment.
